# FP1 - Proposal for Critique
1. The Accessibility Challenge

Basic Idea: Memory-matching game where players match accessible design practices with the corresponding web elements in order to promote awareness of web accessibility.

Interactivity and Engagement: The game will have progressively challenging levels with dynamic visuals and hints. Players will earn rewards, such as badges or points, for correct matches, making the experience more engaging.

Accessibility: The game will include customizable features such as text size adjustments and color contrast options, simplified navigation, and alt text for images.

Information Conveyed: The game will teach players about best practices in accessible web design, such as contrast ratios, keyboard navigation, and proper use of alt text.

2. Personal Finance Dashboard

Basic Idea: An interactive dashboard that helps users track their spending, set budgets, and visualize financial goals to manage personal finances effectively.

Interactivity and Engagement: Users will be able to customize their dashboard layout, set financial goals, and interact with real-time data visualizations, including spending trends and goal progress bars. Interactive tooltips and alerts will notify users of budget deviations or milestones.

Accessibility: The dashboard will have high-contrast themes, keyboard navigation, and clear, and intuitive icons. Users will also be able to adjust text size and switch between dark and light modes.

Information Conveyed: The dashboard will provide users with detailed insights into their spending habits, budget performance, savings goals, and financial health metrics, all presented in an easily digestible format.

3. Personalized Reading Recommendation Tool

Basic Idea: A tool that recommends books based on user preferences, reading history, and genre interests to help users discover new literature.

Interactivity and Engagement: The tool will allow users to set preferences for genres, authors, and formats. It will have an interactive recommendation quiz, as well as personalized book lists and reviews. Users can also rate and review books to refine their future recommendations.

Accessibility: The tool will have accessible features like adjustable font sizes and clear, easy-to-navigate sections. Recommendations will be offered in various formats (audiobooks, ebooks, etc.) for diverse accessibility needs.

Information Conveyed: The tool will display personalized book suggestions, synopses, ratings, and reviews, along with options to filter by genre, author, or reading level.
